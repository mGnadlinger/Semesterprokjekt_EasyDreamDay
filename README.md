# Medientechnik Semesterprokjekt 2. Klasse 
## EasyDreamDay

**EasyDreamDay** ist eine Webapp zur Planung der perfekten Hochzeit. Brautpaare können Hochzeitsinfos eintragen, Einladungen verschicken, Wunschlisten erstellen und Fotos teilen. Gäste können sich anmelden, ihre Teilnahme bestätigen und Inhalte einsehen.

## Features
- Hochzeitsinformationen anzeigen
- Gästeeinladungen mit Zu- und Absagen
- Geschenke- und Wunschlisten
- Kalender mit Checklisten und Erinnerungen
- Fotos teilen

## Technologien
- Frontend: HTML, CSS, JavaScript
- Backend: PHP
- Datenbank: MySQL (Verwaltung über phpMyAdmin)
